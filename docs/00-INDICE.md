# Índice detallado
1. **Resumen ejecutivo** — objetivo, usuarios, módulos, tecnologías, diagrama general.
2. **Mapa de la aplicación** — árbol de rutas; ficha de cada una de las 17 pantallas (ruta, archivo, función, datos que consulta/modifica, dependencias).
3. **Manual del usuario** — procesos operativos paso a paso, sin lenguaje técnico.
4. **Flujos operativos** — 9 procesos completos con diagramas Mermaid + matriz de procesos.
5. **Arquitectura** — Next.js 15 App Router + Server Actions + Prisma + Supabase; estructura de carpetas.
6. **Base de datos** — 11 modelos Prisma, ERD, restricciones, índices, inmutabilidad de auditoría.
7. **Diccionario de datos** — tabla campo/tipo/obligatorio/uso para los modelos principales.
8. **Reglas de negocio y cálculos** — cálculo inverso, IMSS, ISR, primas, descuentos, con archivo y función responsables.
9. **Usuarios y seguridad** — Supabase Auth, middleware, cookies, variables sensibles, riesgos.
10. **Integraciones** — BD de asistencias (solo lectura), Excel (xlsx), Netlify, GitHub.
11. **Despliegue** — pipeline, variables, migraciones, rollback.
12. **Mantenimiento** — cómo tocar pantalla/cálculo/tabla/parámetro con seguridad.
13. **Dependencias** — qué se rompe al modificar qué, con riesgo BAJO→CRÍTICO.
14. **Deuda técnica** — hallazgos con evidencia y clasificación.
15. **Trazabilidad** — cadenas completas UI→BD de las funciones clave.
16. **Glosario** — SD, SDI, SBC, asimilables, neto pactado, UMA, etc.
